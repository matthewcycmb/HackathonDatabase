## Archetypes

1. **Health / assistive wearables (8)** — ESP32/Arduino + IMU + heart-rate + force sensors + OLED + haptics; ESP32-CAM for on-face vision. (Twin, StabiliKnee, CPR Guide, Sun Buddy, Glorp, Cupid Glasses, ShoulderCupid, Cadence)
2. **Outdoor survival / off-grid comms (7)** — ESP32 + GPS + LoRa + IMU + haptics + speaker, battery power. (BreadCrumb Trail, TrailSense, FIeld-Hive, Buzz Kill, minutemesh, Echo-Pro, Dalmatian bot)
3. **Robots / actuated machines (9)** — RPi/ESP32 + servos/steppers + motor driver + webcam + ultrasonic. (Litter Critter, BARK, Sortify, Sentez!, Whackathon, knobbi, AuraShield, Racing Pedals, Please Read Instructions)
4. **Music / conversational audio objects (7)** — mic + speaker/I2S amp + ESP32/RPi + IMU/flex input; ElevenLabs/Gemini upstream. (JamDeck, Fret Follower, pAIMaestro, TeddyTalk, Triad, Polar Bear, Amby)
5. **Vision smart-objects / home monitoring (5)** — RPi/ESP32 + camera + relay + RFID + NeoPixels. (Catatouille, Disco Patrol, BlinkIn, 3D Kiosk, Cuckoo Clock)
6. **Interactive displays (4)** — RPi + LED matrix/POV + IMU. (PixelParty, VideoGlobe, volumetric display, AR Cube Cannon)
